## Step 5 Re-run driver (safe automation snippet)

device-code path は **foreground blocking** (poll loop が ~900s 回り続ける) なので、
Re-run を自動化する時は bg + timeout で止める必要がある。**ただし下記の安全パターン
以外を使うと CCoW セッション自身を撃ち落とす事故が起きる** (issue #59)。

```bash
set -uo pipefail

REPO_DIR=/home/user/github-mcp-server-rs
LOG=/tmp/run-step5.log
PIDFILE=/tmp/step5.pgid
: > "$LOG"
rm -f "$PIDFILE"

unset GITHUB_LOGIN
# setsid で新セッション/プロセスグループを切り出す。内側 `sh -c` で session
# leader 自身が `$$` (= 新 PGID) を PIDFILE に書き出す。後段の `kill -- -PGID`
# は Claude 本体 (別 session) には絶対届かない。
#
# 注意: `$!` から `ps -o pgid=` で取る方式は使わない。`setsid X &` の `$!` は
# setsid wrapper 自身の PID で、fork/exec のタイミングで消えて `ps -o pgid=`
# が空文字を返す事がある (= cleanup 空振り、leak 発生)。PIDFILE 経由が確実。
setsid env \
  GITHUB_MCP_AUTO_DEVICE_FLOW=1 \
  CLAUDE_CODE_REMOTE=true \
  CLAUDE_PROJECT_DIR="$REPO_DIR" \
  GITHUB_MCP_PIN_TAG=v0.0.17 \
  sh -c 'echo $$ > '"$PIDFILE"'; exec bash '"$REPO_DIR"'/.claude/hooks/install-mcp.sh' \
  >"$LOG" 2>&1 < /dev/null &

for _ in $(seq 1 10); do
  [ -s "$PIDFILE" ] && break
  sleep 0.2
done
PGID="$(cat "$PIDFILE" 2>/dev/null || echo "")"
echo "[driver] PGID=$PGID"

# device-code prompt の到達を最大 25s 待つ (binary download + 起動分の余裕込み)
REACHED=""
for i in $(seq 1 25); do
  sleep 1
  if grep -q "Open this URL in your browser" "$LOG" 2>/dev/null; then
    REACHED="${i}s"
    break
  fi
done
echo "[driver] device-code prompt reached: ${REACHED:-NO}"

# プロセスグループ単位で停止 — Claude 本体 (別 session) には絶対届かない。
if [ -n "$PGID" ]; then
  kill -TERM -"$PGID" 2>/dev/null || true
  sleep 1
  kill -KILL -"$PGID" 2>/dev/null || true
fi

echo "[driver] Claude(693): $(ps -p 693 -o stat= 2>/dev/null || echo GONE)"
ps -eo pid,pgid,cmd | grep -E 'install-mcp|github-mcp-server-rs (auth|relay|pair)' | grep -v grep \
  || echo "[driver] no leak"
echo "---tail---"
tail -15 "$LOG"
```

**Do NOT** (issue #59 で session を撃った実例):

```bash
# ❌ pkill -f は cmdline 全体に regex マッチする。CCoW の Claude プロセスは
#   --add-dir /home/user/github-mcp-server-rs … --add-dir /home/user/auth-worker …
#   を cmdline に持つので、この regex がそのまま Claude 本体に当たって SIGTERM。
pkill -f "github-mcp-server-rs.*auth"
```

文字列マッチで止めたい場面では **コマンド名完全一致** のみ可:

```bash
# ✓ -x = exact match on command name (not full cmdline). Claude には届かない。
pkill -x github-mcp-server-rs
```

ルールはこれだけ:

1. driver は `setsid` で別 session を切り出し、**session leader 自身が $$ を PIDFILE に書く**
   形で PGID を捕捉して `kill -- -PGID` で刈る (`$!` 経由は NG)。
2. `pkill -f <regex>` は **smoke-test 手順では禁止**。`<regex>` がいくら狭く見えても
   CCoW の Claude プロセス cmdline は長大で `.*` 一発で巻き込まれる。
3. PID / PGID で止められない取り残しを掃除したい時だけ `pkill -x <exact-cmd>` を許可。
